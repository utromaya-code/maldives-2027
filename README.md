# Мальдивы 2027 — остров и яхта

Одностраничный лендинг йога-путешествия на Мальдивы с Татьяной Ищенко,
**26 марта — 5 апреля 2027**: 6 ночей на острове Дигура (26 марта — 1 апреля) и 4 ночи на яхте (1–5 апреля).
Путешествие продаётся целиком — без участия только в одной из частей.

Статика без сборщиков — работает на GitHub Pages из корня ветки `main`.
Адрес: <https://utromaya-code.github.io/maldives-2027/>

Программа взята с <https://maldivesyogaboat.kray-puteshestviy.ru/> и адаптирована под новые даты и ведущую.

## Структура

```
maldives-2027/
├── index.html    — весь лендинг (CSS и JS внутри файла)
├── favicon.svg
├── fonts/        — Cormorant + Golos Text (WOFF2, самохостинг, кириллица + латиница)
└── img/          — фото (JPG, оптимизированы)
```

## Как поменять цены

В разделе `#price` в файле `index.html` основная стоимость указана в `.amount`, а цены для первых пяти мест, ребёнка от 9 лет и периода после 20 декабря — в `.price-rates`.

## Что изменено относительно исходного сайта

- Даты: 26 марта — 5 апреля 2027 (дни недели проставлены в программе).
- Ведущая — Татьяна Ищенко вместо Ирины Овчинниковой (Ба Цзы) и Дмитрия Края. Блоки про Ба Цзы убраны.
- Из программы убраны авторские практики Дмитрия: мастер-класс по мандалам, гвоздестояние; скидка 15 % на следующую группу; партнёрские промокоды (OpenDive, страховка).
- Звёздность отеля на Дигуре не указана (в исходнике — 3*).
- Убраны повторы текста, капслок и «срочность» («осталось совсем немного времени»), опечатки.
- Цены указаны за весь маршрут; варианты «только яхта» / «только остров» убраны.
- Добавлена карта маршрута (своя SVG-схема вместо недельного круга яхты со старого сайта): паром Мале → Дигура, выезды на Дангети, Омаду, резорт и к китовым акулам, затем паром Дигура → Мале и яхта Мале → Гурайдо → Ваафу → Мале. Генератор карты — `tools/make_map.py` (координаты островов по Википедии); после правок вставить новый `<svg class="map-svg">` в `index.html`.
- Добавлено: блок про яхту, «Встречи в океане», ритм дня, вопросы и ответы (погода, сноркелинг, дресс-код на локальном острове, укачивание, IMUGA), «Что взять» по группам, лайтбокс-галерея, Schema.org Event, OG-превью.
