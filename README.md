# Мальдивы 2027 — яхта и остров

Одностраничный лендинг йога-путешествия на Мальдивы с Татьяной Ищенко,
**25 марта — 4 апреля 2027**: 4 ночи на яхте (25–29 марта) + 6 ночей на острове Дигура (29 марта — 4 апреля).

Статика без сборщиков — работает на GitHub Pages из корня ветки `main`.
Адрес: <https://utromaya-code.github.io/maldives-2027/>

Программа взята с <https://maldivesyogaboat.kray-puteshestviy.ru/> и адаптирована под новые даты и ведущую.

## Как поменять цены

Все цены сейчас скрыты звёздочками. Найдите в `index.html` строку `***` — каждое вхождение одна цена:

- три карточки в блоке «Стоимость» (`<div class="amount">***<sup>USD</sup></div>`): полный маршрут, морское сафари, остров;
- доплата за одноместное размещение (яхта за 4 ночи, остров за ночь);
- допрасходы в списке «Оплачивается отдельно» (перелёт Мале — Маамигили, аренда снаряжения, резорт, массаж, фото/видео);
- предоплата в блоке «Бронирование».
